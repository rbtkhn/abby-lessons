# Abby Lessons

Small, self-contained lessons for use in a family-approved AI chat with caregiver support. Teaching material by Mira. Lesson 005 embeds two caregiver-approved learning connections for Abby; full learner profiles, private records and conversation transcripts are excluded.

## Begin the pilot

Copy this folder URL into your family-approved ChatGPT chat and say **Begin this lesson**:

https://github.com/rbtkhn/abby-lessons/tree/main/lessons/005-a-visitors-first-day

[Open Lesson 005 — Abby’s inventor workshop](lessons/005-a-visitors-first-day)

Lesson 005 now offers three inventor routes: stop rolling pencils, explore paper, or design a picture message. One chosen route is paired with one core regrouping activity. The folder displays its complete lesson in `README.md`. The tutor should retrieve that file, verify the title and revision, then begin. You should not need to navigate individual files. Public visibility does not guarantee retrieval in every chat; the fallback below remains available.

## If the link does not load

Open the [lesson file](lessons/005-a-visitors-first-day/README.md), use GitHub’s **Download raw file** control where available, and attach the downloaded Markdown file to the chat. Or open [the raw text](https://raw.githubusercontent.com/rbtkhn/abby-lessons/main/lessons/005-a-visitors-first-day/README.md), copy all of it, and paste it into the chat. Then say: **Begin the complete Lesson 005 I supplied.** If uploads are unavailable, use paste. No second lesson document or personal-continuity attachment is needed.

## How these packages work

Each lesson folder has one complete `README.md`. Add an `assets/` folder only if essential material is actually supplied, with its purpose and access requirements explained. This pilot includes one optional paper-parts counting diagram with a complete text equivalent. It needs no additional accounts or personal data; inability to display the image does not block the lesson.

The public package ID identifies the activity. `005` is its slot in this collection, not proof that a learner completed four earlier lessons. Anyone may begin here without previous lessons. Private completion records can record the package ID, revision and Git commit actually used. Updating this repository does not update a file already attached to a chat.

Lesson 005 includes the two learning connections explicitly approved for this public packet: earlier imaginative place-making and a number-splitting explanation. This bounded inclusion does not authorize other personal observations. Keep names beyond the intentionally public collection name, contact details, school records, transcripts, portraits, ledgers and completion reviews out of this repository. Share no child’s work or chat through public issues. A lesson can be used without sending anything back.

This is a pilot teaching design, not a tested guarantee of learning or universal ChatGPT access. The first actual use should tell us whether opening it was easy, the choices were clear and the tutor respected the learner’s direction and stopping.
